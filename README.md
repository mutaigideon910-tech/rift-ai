# RIFT AI 🇰🇪 - Kenya's First Free AI
**Built in Eldoret, for Africa, by Gideon**

RIFT AI is a free, open-source AI assistant built to solve local problems — farming, education, business, Sheng & Swahili.

⭐ Star this repo if you love Kenya!

### ✨ Features
- 100% Free & Open Source
- Understands Swahili, Sheng, English
- Lightweight — runs on Chromebook
- Built in Eldoret, Rift Valley

### 🚀 How to Run
git clone https://github.com/mutaigideon910-tech/rift-ai.git
cd rift-ai
pip install -r requirements.txt
python app.py

### 🌍 Mission
Give every Kenyan student free AI without paying dollars.
